# 学术主页交互规范

## 设置菜单

- 设置行之间不加横向分隔线，用留白区分各行。
- 可以保留设置面板的外框和选项按钮的描边；不要把“无行间横线”扩大为移除所有边框。
- 设置仍位于齿轮弹层中，保持简洁，不增加解释性文案。

## 少量选项

- 单个控件少于 5 个选项（1–4 个）时，直接展示选项，不使用原生或自定义下拉列表。
- 单选优先沿用现有分段按钮；也可根据内容使用单选按钮或并列选项。
- 该规则针对控件的取值选项，不要求移除承载设置的齿轮弹层。
- 5 个及以上选项按实际空间和内容选择控件，不强制改用下拉列表。
- 主题的“系统 / 浅色 / 深色”和字号的“大 / 中 / 小”均保留为三段按钮。图标按钮应有可读名称，选中状态使用现有的 `aria-pressed` 与高亮样式。

## 修改位置

- `index.html` 与 `404.html`：两处设置面板保持一致。
- `assets/style.css`：复用 `.settings-row`、`.control-group` 和 `.control-button`；行间只通过间距分隔。
- `assets/theme.js`：设置状态、偏好记忆及中英文控件标签。

调整后检查深浅色、不同字号及窄屏下的选项可读性，不为这些规则增加新的运行时依赖。
